# Объекты без Place ID

Снимок: 1 ноября 2026 года. В атласе 403 карточки, Place ID есть у 92, отсутствует у 311. Отсутствие ID не означает, что у здания нет адреса в Google: это может быть дом без отдельной карточки, объект во дворе, адрес дальше пяти метров от контура или просто несовпадение в радиусе проверки.

Правило прежнее: Place ID добавляется только после проверки, что он относится к тому же зданию и адресу. Адресный ID (`kind=house`) и именованная достопримечательность — разные вещи; в карточке это различается через `googlePlaceIdSource`.

## Как получить актуальный список

```sh
node --input-type=module -e "
import fs from 'fs';
const b = JSON.parse(fs.readFileSync('public/atlas/buildings.json', 'utf8'));
for (const x of b.filter((y) => !y.googlePlaceId)) {
  console.log([x.id, x.name, x.address].join('\t'));
}
"
```

Собранный `buildings.json` здесь используется только для удобства: `name` и `address` — производные поля. Источник — `data/atlas/tbilisi/<id>.json`, где имя и адрес лежат в `names`/`addresses`. Список стоит фильтровать по району или адресу, а не просматривать целиком. Для новых проверок использовать `scripts/batch-google-addresses.py`: он работает с допуском 5 м и сохраняет результат в отдельный отчёт, не меняя карточки.

## Что проверять

- Точка Place ID лежит в контуре или рядом с ним, а не у соседнего корпуса.
- Адрес в Google совпадает с реестровым/атласным, включая буквы и дроби.
- Для именованной достопримечательности тип не `premise`/`street_address`.
- Не переносить Place ID с соседнего объекта и не считать его доказательством исторической даты или авторства.
