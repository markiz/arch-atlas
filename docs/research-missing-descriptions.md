# Объекты без описания и истории: ревизия 89 карточек и 49 находок

Срез: 7 ноября 2026 года. Источник карточек — `data/atlas/tbilisi/*.json`; проверялись только карточки, где вместо описания стоит шаблонная фраза «В OpenStreetMap объект отмечен как историческое здание / памятник культурного наследия».

## Коротко

- В наборе **403** карточки; **89** (22%) имеют шаблонное описание и **ни одна** из них не имеет поля `histories`.
- Это не значит, что данных нет: у **88 из 89** есть Wikidata QID, а по **49** объектам уже есть проверяемые сведения (от полной истории до идентификации по реестру) — из официальных сайтов, Georgian Encyclopedia, Википедии, реестра и исторических очерков Sputnik Georgia.
- Ниже — таблица находок и полный список остальных карточек с приоритетом. Формулировки, где источники расходятся, помечены в колонке «Что проверить».
- Главный пример: у Шахматного дворца им. Ноны Гаприндашвили есть официальный сайт консервационного проекта (Getty Foundation / Blue Shield) с историей, авторами и составом помещений. Карточка просто не была заполнена.

### Пример: Шахматный дворец им. Ноны Гаприндашвили

Карточка `osm-58071533` выглядела почти пустой, но по официальному сайту проекта консервации (Getty Foundation, Blue Shield) известно: здание открыто в 1973 году в парке Вера, авторы — Владимир (Ладо) Алекси-Месхишвили и Германе Гудушаури, инженер — Гурам Мебуке, зал на 520 мест, дворец посвящён пятикратной чемпионке мира Ноны Гаприндашвили. Это не «нет данных», а не заполненная карточка.
