# Статус текущей версии

Предыдущий план — `implementation-plan.md`. Текущая сборка содержит 100 зданий с контурами из OSM. Большая часть новых записей и их фотографии автоматически связаны с OSM/Wikidata/Wikimedia Commons; это исследовательский каталог, а не 100 полностью проверенных редакционных карточек.

## Сделано

- Все объекты имеют Polygon/MultiPolygon; составные отношения OSM разобраны в реальные контуры. Цвет отображается на всех масштабах.
- Убран декоративный текст; добавлен переключатель Тбилиси, Батуми и Кутаиси; для двух последних показано, что данных пока нет.
- Добавлена галерея и атрибуция для каждого изображения; записи без фото явно обозначены.
- Добавлена геолокация только по нажатию с обработкой отказа, ошибки и выхода за пределы подробной карты.
- Данные, геометрии, проверка наименований фото и тесты фильтрации проходят; все ресурсы входят в локальный SHA-256 манифест.

## Требуется дальше

1. Пройти браузерную проверку: карта, мобильная панель, клавиатура, фото и каждое состояние разрешений геолокации; затем запретить HTTP/HTTPS после ready и открыть все карточки.
2. Ручная редакционная проверка контуров, дат, авторов и соответствия фотографий конкретным зданиям; отдельная проверка прав на архитектурные произведения и лицензии.
3. Пополнить фотографии до нескольких на каждый объект; заполнить неизвестные поля только по надежным источникам.
4. Добавить реальные наборы данных других городов, а затем включить их в переключатель.
5. Дополнить модель фаз и источников; обеспечить множественный выбор фильтров и сохранение состояния в ссылке.

Предпросмотр ранее не удалось запустить из-за недоступной инфраструктуры `sites-previewd`. Реальное поведение страницы в браузере, сетевой тест и геолокация остаются непроверенными.
