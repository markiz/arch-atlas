# Документация

Здесь лежит только постоянная документация: схемы данных, правила и архитектурные договорённости, которые остаются верными при развитии проекта.

- Статусы, планы, отчёты, исследовательские журналы и временные таблицы сюда не добавляются — для них есть `work/`.
- Исторические документы и материалы до сброса документации лежат в `archive/2026-11-08-pre-reset/`.
- Документ должен описывать действующую процедуру или явно отмечать, что это целевое устройство; при изменении поведения обновляй его вместе с кодом.

## Документы

- [new-object-pipeline.md](new-object-pipeline.md) — конвейер поиска и обработки новых объектов: независимые дорожки, состояние кандидата, артефакты, review и публикация.
- [photo-refresh.md](photo-refresh.md) — обновление фотографий существующих карточек: отбор пробелов, свободные лицензии, визуальная сверка, предложения субагентов и импорт.
