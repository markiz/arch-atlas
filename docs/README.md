# Документация

Здесь лежит только постоянная документация: схемы данных, правила и архитектурные договорённости, которые остаются верными при развитии проекта.

- Статусы, планы, отчёты, исследовательские журналы и временные таблицы сюда не добавляются — для них есть `work/`.
- Исторические документы и материалы до сброса документации лежат в `archive/2026-11-08-pre-reset/`.
- Документ должен описывать текущее состояние кода и данных; при изменении поведения обновляй его вместе с кодом.

Действующих документов пока нет. Базовые инструкции для людей — в `../README.md`.
