# Источники данных для Белграда

Документ фиксирует, откуда берутся объекты, геометрия и факты для белградского атласа, чем источники отличаются и что каждый из них не доказывает. Текущие выгрузки и отчёты кампании лежат в `work/`, а не здесь.

## Обязательные источники

| Источник | Что даёт | Ограничения |
|---|---|---|
| OpenStreetMap, Overpass API и региональный PBF Geofabrik | Контуры зданий `Polygon`/`MultiPolygon`, адреса, теги `heritage`, `historic`, `building`, `wikidata`, `ref:RS:*` | ODbL. Теги отражают состояние базы, а не юридический статус. Контур может описывать часть комплекса или устаревшую редакцию. |
| Републички завод за заштиту споменика културе, `heritage.gov.rs` | Государственный реестр непокретных культурных добара, категории охраны, решения | Публичный реестр не имеет стабильного открытого API; списки и карточки нужно сохранять как снимок источника. |
| Завод за заштиту споменика културе града Београда, `beogradskonasledje.rs` | Городской список по общинам: название, адрес, категория, решения о защите | Страницы по общинам не дают отдельного URL на объект. Совпадение названия и адреса — это сопоставление, а не тождество. |
| Информациони систем непокретних културних добара, `nasledje.gov.rs` | Государственная карточка объекта: адрес, датировка, категория, `Опис непокретног културног добра` с историей и библиографией, координаты | Описание — авторский текст республиканского завода, а не нейтральная справка; оно может быть длиннее карточки и включать архитектурный разбор. Постоянного публичного URL с человекочитаемым адресом нет; снимок обязателен. |
| Wikidata | QID, названия на языках города, `P571` (дата), `P84` (архитектор), `P149` (стиль), `P18` (изображение), `P1435` (категория охраны), `P131` (община) | CC0, но значения бывают неполными, устаревшими или относятся к учреждению, а не к зданию. `P571` у музея или банка часто означает год основания, а не постройки. |
| Wikimedia Commons | Фотографии со свободной лицензией, автор, лицензия, страница файла | Только CC0/PD/CC BY/CC BY-SA без NC/ND. `P18` — указатель, а не доказательство: кадр проверяется визуально. |
| Wikipedia (sr/en/ru/uk) | Библиографические зацепки, альтернативные названия, история | CC BY-SA. Текст не копируется в карточку; используется как указатель на первоисточник. |
| Nominatim | Проверка адреса и координат, поиск OSM-объекта | ODbL, лимит запросов. Обратное геокодирование без совпадения адреса не подтверждает объект. |

## Тексты

Для описаний и историй приоритет иной, чем для геометрии: карточка объекта в ИС НКД и решения Републичког и Градског завода, научный журнал «Наслеђе», официальные истории учреждений, профессиональные гиды и монографии. Поле `Опис непокретног културног добра` — основной нарративный источник: оно даёт датировку, авторство, назначение и дальнейшую судьбу объекта. Wikipedia — указатель и вторичная сводка, а не единственное доказательство. Полная процедура, формат claims и правила четырёх языков — [text-pass.md](text-pass.md).

## Порядок отбора

1. Берётся сохранённый PBF Сербии и из него — замкнутые `way`/`relation` с `heritage=*` и реальным контуром здания в границах города.
2. Контуры больше 20 000 м², кладбища, парки, археологические площадки и пространственные целины отбрасываются: это не здание, а территория.
3. Дубликаты склеиваются по `wikidata`; группа из нескольких корпусов с одним QID не превращается в несколько карточек без отдельного контура.
4. Объект сопоставляется с городским списком по нормализованному названию и адресу. Совпадение используется для адреса и ссылки на официальную страницу, но не отменяет проверку контура.
5. Публичные здания вне `heritage` добавляются только как исключение: парламент, музеи, театр, банк, архив. Массовая загрузка жилых домов запрещена.
6. `P571` принимается как год постройки только для зданий. Для музеев, банков, библиотек и других учреждений год основания не подставляется.

## Языки и имена

Языковой контракт города — `ru`, `en`, `uk`, `sr`. Приоритет имени: `name:sr`/`name` OSM, затем `name:ru`/`name:en`/`name:uk` OSM, затем соответствующий label Wikidata, затем курируемый перевод. Механическая транслитерация допустима только для имён собственных: сербские падежные формы и служебные слова не переносятся в русское или украинское название. Для каждого объекта `ru` и `uk` — самостоятельные формулировки, а не сербская кириллица с заменой отдельных слов. Регрессию ловит `tests/belgrade-names.test.mjs`.

Адрес собирается из `addr:street` + `addr:housenumber`, `P6375` или адреса городского списка. Названия улиц переводятся, а не переносятся в сербской форме: «Бульвар Короля Александра», а не «Бульвар краља Александра». Если улицы нет, допускается locality-адрес вида «община, Белград»; это пробел, а не точный адрес.

## Что проверяется перед публикацией

- контур замкнут, лежит в границах города, площадь правдоподобна для здания;
- имя и адрес есть на всех четырёх языках, пустые значения не маскируются переводом;
- `styleIds` — из справочника, `undetermined` допустим и означает «не установлен»;
- архитектор указан только при наличии `P84` или другого источника;
- фотография имеет свободную лицензию, автора, страницу файла и прошла визуальную сверку;
- `source` ведёт на официальную страницу города или на OSM-объект, `otherSource` — на Wikidata;
- карточка проходит `npm run check`, а сборка — `npm run build` и `npm run verify`.

## Известные ограничения

- Городской реестр не публикует машиночитаемый API и постоянные URL объектов; ссылка ведёт на страницу общины.
- У части объектов нет года, стиля или архитектора в открытых источниках. Это фиксируется как `undetermined`/пустое поле, а не заполняется догадкой.
- Описания и истории заполнены у всех 200 объектов; 486 gaps фиксируют отсутствующие в источниках факты и расхождения досье с НКД.
- Фотографии есть не у всех объектов; отсутствие кадра — это пробел, а не повод подставить чужое изображение.
- Контуры OSM могут описывать главный объём, а не весь комплекс; для ансамблей выбирается один корпус.
