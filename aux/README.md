# Городские aux-справочники

Здесь лежат вторичные данные, на которые ссылаются карточки атласа. Для каждого города — свой каталог:

```text
aux/tbilisi/
  styles.json        архитектурные стили
  architects.json    архитекторы
  districts.json     районы
  year-labels.json   подписи датировок
```

Формат — объект `ID -> запись`:

```json
{
  "empire": {
    "source": "Ампир",
    "labels": {"ru": "Ампир", "en": "Empire", "ka": "ამპირის სტილი", "uk": "Ампір"}
  }
}
```

- `ID` стабилен и не меняется при редактуре подписи.
- `labels` обязателен и содержит ровно `ru`, `en`, `ka`, `uk`; пустые строки не допускаются.
- `source` необязателен: это исходная подпись, по которой запись искали. Основная русская подпись — `labels.ru`.
- Не дублируйте подписи в карточках: там остаются только `styleId`, `architectIds`, `districtId`, `yearLabelId`.

`npm run aux:merge` проверяет файлы и склеивает их в `data/aux/<city>.json` — единый JSON города для сборки. Он генерируется, в Git не хранится и вручную не редактируется. `npm run build`, `npm run check` и Vite dev-сервер вызывают merge автоматически.

При добавлении нового стиля, архитектора, района или подписи даты сначала добавьте запись сюда, затем используйте её ID в карточке. `scripts/validate_cards.py` проверяет, что все ссылки из `data/atlas/<city>/` существуют.
